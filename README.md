# Floristería Rossi

Catálogo web para Floristería Rossi, desarrollado con React, TypeScript, Vite y Tailwind CSS.

## Características

- Catálogo modular por categorías
- Diseño minimalista y responsive
- Enlaces directos a WhatsApp para consultas de diseño
- Hero con banner y logo SVG personalizado
- Lazy loading para secciones principales

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS

## Instalación

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
